## 車選びの軸（本人の要望）

- 🎧 **音楽を良い音で聴きたい**（オーディオ重視）→ EVは静粛性が高くオーディオ最強クラス。Model Y純正は高評価
- 🛣️ **長距離運転の予定あり** → 航続500〜600km＋スーパーチャージャー網。冬は航続2〜3割減/地方の充電器は要計画
- 🚗 **運転好き**（速さ・快適さ志向。エンジン音は不要）→ Model Yの滑らかな加速で満足度高
- 🏕️ **車中泊したい** → Model Yのキャンプモード（空調つけっぱで安全に就寝・消費10〜15%）が大きな強み
- → 上記すべて Model Y がど真ん中で合致。エンジン音目的ではないのでEVで問題なし

## ローン内容（テスラ見積もりスクショより）

- 据置（バルーン）型ローン
- 頭金: 200万
- 月々: ¥55,100 × 60ヶ月（5年）
- 据置率: 30% → 据置価格 ¥1,972,800（最後にまとめて精算）
- 総額イメージ: 頭金200万 + 月々合計330.6万 + 据置197万 ≈ **728万**（金利分 約70万）

## 方針: 5年で乗り換え

バルーンローンと相性◎。5年後の動き:

1. 今のModel Yを中古で売却（一括査定で複数社競わせる＝下取りより高い）
2. 売却額で据置197万を精算
3. 余りを次の車の頭金へ → 乗り換え

### 5年後の売却シミュレーション

| シナリオ | 売却額 | 197万精算後 |
|---|---|---|
| 強気 | 約330万 | +130万 |
| 標準 | 約290万 | +90万 |
| 弱気 | 約230万 | +30万 |
| 最悪（EV相場急落） | 197万以下 | ±0〜マイナス |

唯一のリスク = EV中古相場の急落。

## 補助金（2026-06-28 時点で調査済み）

- **国のCEV補助金: Model Y = 127万円**（2026年度・テスラは維持/増額）← デカい
- **神奈川県: 個人の車両購入は対象外**（県補助は事業用＆充電設備のみ）
- **大和市: 独自のEV購入補助なし**
- → もらえるのは **国の127万のみ**（県・市の上乗せゼロ）
- 補助金はローンを直接安くするのではなく、**購入数ヶ月後にキャッシュバック**で入る → 繰上返済に回すのが◎
- 🚨 予算枠が埋まると受付終了（早い者勝ち）
- 🚨 保有義務期間（BEVは概ね4年）あり → 途中売却で返納。**5年乗り換えなら4年クリアで返納なし✅**
- ※金額・条件は毎年度（4月）変わる → **購入年度の最新条件・予算枠残を購入前に必ず確認**
- 出典: tesla.com/support/incentives, touchlab.jp(2026/03), pref.kanagawa.jp(f4259)
