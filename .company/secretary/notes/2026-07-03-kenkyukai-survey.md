# 研究会アンケートフォームの設問設計

## 背景・きっかけ
研究会のアンケートフォームを修正する必要がある。目的は「参加者の満足度・感想を知りたい」こと。

## 議論・思考メモ
満足度調査は次の3ブロックで構成すると、集計しやすく・自由記述も拾えるバランスになる。

1. **定量評価（5段階評価、集計・比較しやすい）**
2. **定性評価（自由記述、次回改善のヒントを拾う）**
3. **属性（任意、参加者層の把握用）**

## 結論・ネクストアクション

### 設問案

**A. 定量評価（5段階: とても満足〜とても不満）**
- [ ] 今回の研究会全体の満足度
- [ ] 発表・議論の内容の分かりやすさ
- [ ] 時間配分・進行のペース
- [ ] 会場・開催形式（対面/オンライン）の満足度

**B. 定性評価（自由記述）**
- [ ] 特に良かった点は？
- [ ] 分かりにくかった点・改善してほしい点は？
- [ ] 次回扱ってほしいテーマ・話してほしい人は？
- [ ] その他自由コメント

**C. 属性（任意回答）**
- [ ] 所属（学年・研究室など）
- [ ] 参加回数（初参加／〜回目）
- [ ] 参加形式（対面／オンライン）

### 運用ネクストアクション
- [ ] 上記たたき台をベースにフォーム（Googleフォーム等）を修正する
- [ ] 必須/任意の切り分けを決める（属性は任意推奨、満足度は必須推奨）
- [ ] 過去に配布したアンケートがあれば設問を見比べて重複・過不足を確認する
