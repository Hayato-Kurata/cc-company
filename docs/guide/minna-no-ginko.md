# みんなの銀行の使い方ガイド

みんなの銀行は福岡フィナンシャルグループが運営する完全デジタルの銀行です。スマホだけで口座開設から日常の取引まですべて完結します。

## 基本的な使い方

### 口座開設

スマートフォンアプリをダウンロードし、以下の手順で開設できます。

1. アプリをインストール（iOS / Android）
2. 本人確認書類（マイナンバーカードまたは運転免許証）を用意
3. アプリの案内に沿って入力・撮影
4. 最短翌営業日に口座開設完了

### 基本サービス

| 機能 | 内容 |
|------|------|
| Visaデビットカード | 口座開設と同時に発行。クレジットカードのように使える |
| ATM出金 | イオン銀行・ローソンATM等で利用可能 |
| 振込・送金 | アプリから24時間いつでも可能 |
| 金利 | 普通預金でも比較的高い金利を提供 |

## クレジットカードの引き落としについて

クレジットカードの引き落とし口座にみんなの銀行を設定することは**可能**ですが、いくつか注意点があります。

### 設定方法

1. クレジットカード会社のサイトから「引き落とし口座の変更」を申請
2. みんなの銀行の口座番号・支店名を入力
3. 変更が反映されるまで1〜2ヶ月かかる場合あり（その間は旧口座から引き落とし）

### 注意点

- **残高管理が重要**：デビットカードと同じ口座なので、使いすぎると引き落とし時に残高不足になる
- **引き落とし日前に入金確認**：自動的に不足分を補填する機能はないため、引き落とし前日までに残高を確認する
- **一部カードは非対応**：カード会社によっては新興デジタル銀行を引き落とし口座として設定できない場合がある

### 残高不足を防ぐ運用例

```
メインバンク（給与振込）→ 毎月決まった金額を自動送金 → みんなの銀行
```

みんなの銀行では定期的な自動入金の設定はできないため、別サービス（PayPay銀行の自動送金など）を経由する方法が有効です。

## ポイントが貯まらない問題

みんなの銀行には**独自のポイントプログラムがありません**。これはデジタル銀行としてのコスト削減によって高金利・手数料無料を実現するためのトレードオフです。

### ポイントを最大化する組み合わせ

みんなの銀行 単体でポイントを貯めることはできませんが、**ポイントが貯まるクレジットカードと組み合わせる**ことで補えます。

**おすすめの使い分け**

```
日常の支払い
├── ポイント還元率の高いクレジットカードで決済 → ポイント獲得
├── クレカ引き落としはみんなの銀行に集約 → 残高管理をシンプルに
└── ATM・送金はみんなの銀行のVisaデビットで → 手数料を抑える
```

**相性の良いクレジットカード例**

| カード | 特徴 |
|--------|------|
| 楽天カード | 楽天ポイント1%還元、年会費無料 |
| PayPayカード | PayPayポイント1%還元 |
| Olive（三井住友） | 最大5%還元（条件あり） |
| リクルートカード | 1.2%還元、年会費無料 |

## 一番良い使い方

**「ポイントはクレカで稼ぎ、口座管理はみんなの銀行でシンプルに」** が最もバランスの取れた運用です。

### 推奨パターン

```
給与
 └→ 生活口座（メインバンク）
      └→ クレジットカードで日常支払い（ポイント獲得）
           └→ 引き落としはみんなの銀行
                └→ みんなの銀行Visaデビットは現金が必要な場面・ATMのみ使用
```

### みんなの銀行が特に向いている用途

- **貯蓄用口座**：普通預金でも金利が高めなので、使わないお金の一時置き場に
- **緊急用の予備口座**：ATM手数料が無料（条件あり）で、緊急時にすぐ引き出せる
- **サブ口座**：固定費の引き落とし専用口座として管理をシンプルにする

### みんなの銀行が向いていない用途

- 住宅ローンの引き落とし（対応していないことが多い）
- ポイ活のメイン口座
- 給与振込口座（会社の規定により制限がある場合あり）

## よくある質問

**Q: みんなの銀行だけで生活できますか？**
A: 可能ですが、ポイントが貯まらない点とATM利用の条件を確認した上で、クレジットカードとの併用を推奨します。

**Q: Visaデビットカードとクレジットカードの違いは？**
A: デビットカードは即時引き落としで審査なし。クレジットカードは翌月まとめて請求でポイントが貯まります。みんなの銀行のデビットカードはVisaネットワークで使えますが、ポイントは付きません。

**Q: クレジットカードの引き落とし設定はいつ変更が反映されますか？**
A: 申請から反映まで通常1〜2ヶ月かかります。変更月の引き落としは旧口座から行われることが多いため、旧口座の残高も引き落とし日まで維持しておきましょう。
