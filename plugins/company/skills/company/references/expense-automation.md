# 経費入力自動化（小学館 経費精算シート）

経理部署が、レシートや口頭メモから小学館の「外部協力者用経費精算シート」を
自動作成するためのリファレンス。秘書／経理が会話の中で呼び出して使う。

ツール本体: リポジトリの `tools/expense/`（`fill_expense.py` ＋ `template.xlsx`）。

## いつ使うか

- ユーザーが「経費つけて」「今月の経費まとめて」「精算シート作って」と言ったとき
- レシート画像を渡されたとき
- 「出社◯日と◯日」「取材で◯◯行った」など交通費を伝えられたとき

## ワークフロー

1. **明細を集める**
   - レシート画像 → 日付・支払先・金額・税率（8%/10%）・適格請求書番号の有無を読み取る
   - テキスト → そのまま明細化
   - 不明点（税率・摘要・訪問先）は確認するか、妥当な既定値を使う
2. **JSON を組み立てる**（フォーマットは `tools/expense/README.md` 参照）
3. **スクリプトを実行**して Excel を出力
   ```bash
   cd tools/expense
   python3 fill_expense.py <入力>.json -o <YYYY-MM>_経費.xlsx
   ```
4. **完成版を渡す**。合計・消費税・請求金額は Excel で開くと数式が自動計算される。
5. 経理フォルダに記録を残す（`finance/expenses/YYYY-MM.md` に明細サマリーを追記）。

## 交通費は最優先で簡単に

中央林間⇔神保町の出社は固定パターン（電車・1,180円・インボイスあり）。
ユーザーが「16・18・20・26・27日に出社」と言ったら、確認は最小限にして
`出社日` 配列に日付を並べるだけでよい。

```json
"出社日": ["2026-02-16", "2026-02-18", "2026-02-20", "2026-02-26", "2026-02-27"]
```

取材など内容が違う移動だけ `交通費` 配列で個別に書く。

## 注意点（小学館ルール）

- 明細は1枚20行まで。超えたら分割して複数シートにする。
- 領収書は小学館宛・原本。証票番号は明細の番号と一致させる（スクリプトが自動採番）。
- 1枚の領収書で税率が混在する場合は税率ごとに行を分ける。
- 適格請求書番号がない支払いはインボイス欄を `false` にする。
- 提出は使用日から1ヶ月以内。
