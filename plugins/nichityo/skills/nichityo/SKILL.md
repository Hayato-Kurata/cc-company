# 日程調整スキル

## いつ使うか

- `/nichityo` を実行したとき
- 「日程調整」「いつ空いてる」「候補日」「スケジュール調整」と言われたとき

---

## ワークフロー

### Step 1: 条件を選択式UIでヒアリング

`AskUserQuestion` で以下の**3問を同時に**表示する（すべて選択式）。

#### Q1: 何する？
```
options:
  - 🍺 飲み
  - 🍜 ランチ
  - ☕ カフェ
  - 🎮 遊び
  - 🎬 映画・ライブ
  - ⚽ スポーツ・アウトドア
  - 💼 打ち合わせ
```

#### Q2: いつ頃？
```
options:
  - 今週中
  - 来週
  - 再来週
  - 今月中
  - 来月
```

#### Q3: オンライン・オフライン？
```
options:
  - 📍 オフライン
  - 💻 オンライン
  - どっちでもOK
```

3問すべて選択されたら次のステップへ。

---

### Step 2: Google Calendar の確認

`mcp__Google_Calendar__list_calendars` が使えるか確認する。

- **使える** → Step 3a（カレンダー自動取得）
- **使えない** → Step 3b（手動で空き日指定）

---

### Step 3a: カレンダーから空き時間を自動取得

`mcp__Google_Calendar__list_events` で指定期間のすべてのカレンダーの予定を取得する。

取得対象のカレンダー:
- 倉田速音（個人）
- Orコミュニティ MTG
- SFC
- Steenz
- ToDo リスト
- すずかんゼミ
- インターウォーズ
- プライベート
- 家族
- 研究
- 移動時間

これらすべての予定をもとにブロックされている時間を把握し、カテゴリー別デフォルト（後述）に従って空き時間から**4個の候補**を生成する → Step 4へ。

---

### Step 3b: 手動で空き日を追加指定

カレンダーが使えない場合のみ、追加で1問聞く。

#### Q4: 埋まってる日・時間帯は？（自由入力）
> 例: 毎週月曜AM、7/10〜12は不在、夜は基本NG
>
> ない場合はそのままスキップしてください

入力された情報から**4個の候補日時**を生成する → Step 4へ。

---

### Step 3: 候補日の出力

以下のフォーマットで出力する（コピペしやすいシンプルな形）:

```
【候補日】🍺飲み｜📍渋谷

① 7月5日（土）19:00〜21:00
② 7月6日（日）18:00〜20:00
③ 7月8日（火）19:00〜21:00
④ 7月12日（土）18:30〜20:30

どれかある？なければ別の日程も出せるよ！
```

カテゴリーアイコンの目安:
- 🍺 飲み　🍜 ランチ　☕ カフェ　🎮 遊び　🎬 映画　⚽ スポーツ
- 💼 打ち合わせ　💻 オンライン通話

場所の表記:
- オフライン → `📍〇〇（エリアや駅名）`
- オンライン → `💻オンライン`
- どちらでもOK → アイコンなし、末尾に「オンでもオフでもOK！」

出力後、`AskUserQuestion` で以下の選択肢を表示する:

```
options:
  - ✅ これでOK（コピー用にそのまま表示）
  - 🔄 別の候補を出して
  - ✂️ この日を外す（外したい日を選択）
  - 💬 LINE風にして
  - 📧 メール文章も作って
```

「この日を外す」が選ばれた場合、候補日の一覧を選択肢として表示し、外す日をタップで選べるようにする。

---

## カテゴリー別デフォルト

カテゴリーが指定された場合、以下をデフォルトとして候補日時を生成する。ユーザーが明示的に指定した場合はそちらを優先。

| カテゴリー | 所要時間 | 推奨時間帯 | 備考 |
|-----------|---------|-----------|------|
| 飲み | 2〜3時間 | 平日18時以降、週末18時以降 | 終電を考慮 |
| ランチ | 1〜1.5時間 | 12:00〜13:30 | 平日・週末どちらも可 |
| カフェ | 1〜2時間 | 午後（13時〜17時） | 週末が取りやすい |
| 遊び（ショッピング・観光など） | 半日〜終日 | 週末10時〜 | 平日休みも考慮 |
| 映画・ライブ | 2〜4時間 | 夕方〜夜 | 開演時間に合わせる |
| スポーツ・アウトドア | 半日〜終日 | 週末朝〜昼 | 天気に左右されることを一言添える |
| 仕事・打ち合わせ | 1〜2時間 | 平日10〜18時 | オンライン推奨 |
| オンライン通話 | 1〜2時間 | 夜（20時〜22時）または週末 | 移動不要なので時間の融通が利く |

カテゴリーが不明・その他の場合は、2時間・夕方〜夜をデフォルトとする。

---

## 出力のコツ

- **常に4個**出す
- **土日・平日・夜**を混ぜると相手が選びやすい
- 候補日は**連続した日程を避ける**（分散させる）
- 日付は「7月5日（土）」形式で曜日も入れる
- 末尾に一言添える（「どれかある？」など）と返信しやすい

---

## 再生成ルール

- 「別の候補」→ 前回と重複しない日程で再生成
- 「〇日は外して」→ 指定日を除いた候補を再生成
- 何度でも再生成できる。ユーザーが「これでOK」と言うまで続ける

## カジュアル文体の例

オフラインの場合:
```
来週あたりどう？渋谷で！
① 7/5（土）14時〜
② 7/6（日）13時〜
③ 7/8（火）夜19時〜

どれかある？✌️
```

オンラインの場合:
```
来週あたりどう？オンラインで！
① 7/5（土）14時〜
② 7/6（日）13時〜
③ 7/8（火）夜19時〜

どれかある？🙌
```
