# 一般社団法人 設立支援スキル

## いつ使うか

- `/shadan` を実行したとき
- 「一般社団法人」「社団法人を作りたい」「法人設立」「非営利法人を立ち上げたい」と言われたとき

一般社団法人は、非営利型・営利型どちらの運営も選べる使い勝手のよい法人格。
このスキルは**設立までの流れを迷わず進められる**ように、ヒアリング → 定款ドラフト →
手続きロードマップ → 費用の順で伴走する。

> ⚠️ **免責**: このスキルは実務の下準備を助けるものであり、法的助言ではありません。
> 定款認証手数料・登録免許税などの金額や必要書類は制度改正で変わります。最終的な内容は
> **公証役場・法務局・司法書士／行政書士・税理士**に確認してください。冒頭でこの旨を一度だけ伝える。

## ワークフロー

### Step 1: 基礎知識をひとことで共有

まず、一般社団法人の要点だけ短く伝える（長くしない）。

```
一般社団法人は「人の集まり（社員）」を基盤にする法人です。要点だけ:

・設立時社員（発起人）は 2名以上 必要（個人でも法人でもOK）
・理事は 1名以上 必要
・資本金・基金は不要（0円でも設立可）
・「非営利型」にすると税制メリットがあるが、要件と機関設計が変わる

では、あなたの構想を教えてください。
```

### Step 2: 選択式UIでヒアリング

`AskUserQuestion` で以下を聞く。**まず Q1〜Q3 を同時に**表示し、その後 Q4〜Q6 を表示する
（一度に4問まで）。自由入力が必要なものは選択肢に「その他」を用意して促す。

#### Q1: どんな活動をする法人？
```
options:
  - 🎓 教育・人材育成
  - 🤝 地域・コミュニティ支援
  - 🏥 医療・福祉・介護
  - 🎨 文化・芸術・スポーツ振興
  - 🌱 環境・まちづくり
  - 💼 業界団体・資格認定
  - 🔬 研究・調査・啓発
```

#### Q2: 税制はどうする？
```
options:
  - 非営利型（税制メリット重視）
  - 営利型（普通法人・柔軟な運営重視）
  - まだ決めていない（相談したい）
```
> 補足として簡潔に: 非営利型は収益事業以外が非課税になる一方、剰余金の分配禁止・
> 理事構成（親族比率など）に要件がある。迷う場合は税理士に確認を勧める。

#### Q3: 主たる事務所はどこ？（都道府県だけでOK・自由入力）
> 例: 東京都渋谷区 / 大阪府 / 未定（自宅を予定）

#### Q4: 設立時社員は何名？（2名以上・自由入力可）
```
options:
  - 2名
  - 3名
  - 4名以上
```

#### Q5: 機関設計は？
```
options:
  - 理事1名のみ（最小構成）
  - 理事複数（代表理事を定める）
  - 理事会 + 監事を設置（ガバナンス重視）
```
> 非営利型を選んだ場合は、理事3名以上・監事1名以上が実務上おすすめであることを一言添える。

#### Q6: 事業年度の区切りは？
```
options:
  - 3月末（4月〜翌3月）
  - 12月末（1月〜12月）
  - その他（自由入力）
```

不足情報（法人名の希望など）があれば、この後の会話で自然に聞き取る。

### Step 3: 定款ドラフトを生成

`references/teikan-template.md` を読み込み、ヒアリング結果を差し込んで**定款のドラフト**を生成する。

- 選んだ機関設計・税制・事業年度に応じて条文を出し分ける（テンプレ内の分岐に従う）
- 法人名が未定なら「一般社団法人〇〇」でプレースホルダを残し、命名のヒントを添える
- 目的（第3条）は Q1 の活動分野をもとに 2〜4項の具体的な事業を提案し、
  「（　）事業」の形で列挙する。非営利型なら「剰余金を分配しない」旨を明示
- ドラフトは**そのまま公証役場のチェックに出せる叩き台**であることを明記し、
  空欄・要確認箇所は `〔要確認〕` で目立たせる

### Step 4: 手続きロードマップと費用を提示

`references/setup-checklist.md` を読み込み、その人の状況に合わせたチェックリストを出す。

- 設立までの流れを**番号付きステップ**で提示（定款作成 → 認証 → 登記 → 開業届出）
- 各ステップに「誰が・どこで・何を」を1行で添える
- 費用は概算テーブルで提示し、**電子定款なら印紙税は元々不要**である点など要点を補足
- 最後に「次にやること」を1〜3個に絞って提案（例: 法人名を決める／設立時社員の同意を取る）

### Step 5: 成果物の保存

`.company/` があれば `secretary/notes/` に、なければカレントに、以下を保存するか確認する。

- `一般社団法人設立-定款ドラフト-YYYY-MM-DD.md`
- `一般社団法人設立-手続きチェックリスト-YYYY-MM-DD.md`

保存後、「変更したい点があればいつでも言ってください。定款の文言も調整できます」と伝える。

## 対話のトーン

- 秘書のように丁寧だが、専門用語は噛み砕く（「発起人＝最初のメンバー」など）
- 一度に情報を詰め込まず、ステップごとに区切る
- 金額・書類は必ず「最新は要確認」を添える（過信させない）
- ユーザーの言語を検出し、同じ言語で応答する

## 再依頼への対応

- 「定款を営利型に変えて」→ 該当条文を差し替えて再生成
- 「理事を増やしたい」→ 機関設計を更新して定款・チェックリストを再生成
- 「費用だけ知りたい」→ Step 4 の費用テーブルのみ提示
- 何度でも調整可能。ユーザーが納得するまで続ける
