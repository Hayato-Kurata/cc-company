# 一般社団法人 設立 手続きチェックリスト

設立までの流れ・必要書類・費用のリファレンス。ヒアリング結果に合わせて出し分ける。

> ⚠️ 金額・書類は制度改正で変わります。最新は公証役場・法務局・専門家に確認してください。

---

## 設立までの流れ（4ステップ）

### ① 事前準備・基本事項の決定
| やること | 誰が | ポイント |
|---------|------|---------|
| 法人名を決める | 設立時社員 | 「一般社団法人」を必ず前後どちらかに付ける。既存法人と同一住所・同一名称は不可 |
| 設立時社員（2名以上）を確定 | 発起人 | 個人・法人どちらでも可。全員の同意で定款を作る |
| 事業目的・機関設計を決める | 発起人 | 非営利型なら理事構成・残余財産の要件に注意 |
| 事務所所在地を決める | 発起人 | 定款は市区町村まで、登記は番地まで必要 |
| 法人の実印（代表者印）を作成 | 代表理事 | 登記の際に印鑑届が必要（オンライン申請では任意化されつつある） |

### ② 定款の作成と認証
| やること | 誰が・どこで | ポイント |
|---------|------------|---------|
| 定款を作成 | 設立時社員全員 | 目的・名称・所在地・社員資格・事業年度などを記載 |
| 定款を認証 | 公証役場（本店所在地の都道府県内） | 一般社団法人の定款は**公証人の認証が必須** |
| 電子定款の利用 | 行政書士等 or 自身で | PDF＋電子署名。**一般社団法人の定款は元々印紙税が不要**（紙でも4万円の印紙は不要） |

### ③ 設立登記
| やること | 誰が・どこで | ポイント |
|---------|------------|---------|
| 設立時理事の就任承諾書を用意 | 各理事 | 監事を置く場合は監事分も |
| 設立時社員の決議書を用意 | 設立時社員 | 設立時理事・代表理事の選任内容 |
| 登記申請 | 代表理事 → 法務局 | **登記した日が法人の成立日** |
| 登録免許税を納付 | 代表理事 | 一般社団法人は**一律6万円** |
| 印鑑届出 | 代表理事 → 法務局 | 法人実印を登録（オンライン申請時は任意の場合あり） |

### ④ 設立後の届出
| 提出先 | 主な書類 | 期限の目安 |
|--------|---------|-----------|
| 税務署 | 法人設立届出書、青色申告の承認申請書、給与支払事務所等の開設届 | 設立後すみやか（青色は3か月以内目安） |
| 都道府県・市区町村 | 法人設立届出書 | 各自治体の定めによる |
| 年金事務所 | 健康保険・厚生年金の新規適用届 | 役員報酬・従業員がいれば必要 |
| 労働基準監督署・ハローワーク | 労働保険・雇用保険の届出 | 従業員を雇う場合 |

## 費用の概算

| 項目 | 概算 | 備考 |
|------|------|------|
| 定款認証手数料（公証人） | 約 3〜5万円 | 一般社団法人は資本金概念がないため定額。最新額は公証役場で要確認 |
| 定款の謄本交付手数料 | 約 2,000円前後 | ページ数による |
| 定款の印紙税 | **0円** | 一般社団法人の定款は印紙税の課税対象外（紙・電子問わず不要） |
| 登録免許税（設立登記） | **6万円** | 一律 |
| 法人実印・銀行印の作成 | 数千〜1万円程度 | 任意 |
| 専門家報酬（依頼する場合） | 5〜15万円程度 | 司法書士・行政書士に依頼する場合の目安 |
| **自分で手続きした場合の合計** | **概ね 11〜12万円前後** | 認証手数料＋登録免許税が中心 |

## 非営利型を選ぶ場合の追加ポイント

「非営利型一般社団法人」にすると、収益事業以外の所得が非課税になるなどの税制メリットがある。
代わりに、主に次の要件を満たす必要がある（定款と運営の両面で）。

- 剰余金を社員に分配しない旨を定款に定める
- 解散時の残余財産を、国・地方公共団体・公益法人等に帰属させる旨を定款に定める
- 各理事について、親族等（3親等以内など特殊関係者）が理事総数の3分の1以下であること
- 特定の個人・団体に特別の利益を与えないこと

要件を1つでも外れると普通法人扱いに戻る。**判断は税理士に相談**するのが確実。

## 「次にやること」の提案テンプレ

チェックリスト提示後、状況に応じて1〜3個に絞って提案する。

- 法人名がまだ → 「まず法人名の候補を2〜3個決めましょう」
- 社員が1名構想 → 「設立時社員はもう1名必要です。共同発起人の当てはありますか？」
- 税制未定 → 「非営利型か普通型かで定款が変わります。税理士に一度相談しますか？」
- 定款が固まった → 「管轄の公証役場に定款案を事前チェックに出すのが次の一手です」
