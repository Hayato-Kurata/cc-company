# 経費入力自動化（小学館 経費精算シート）

小学館「外部協力者用経費精算シート」を、明細を渡すだけで自動入力するツール。
合計・消費税・請求金額はテンプレート内の Excel 数式が自動計算するため、
**入力するのは明細行だけ**で完成する。

## 構成

| ファイル | 内容 |
|---------|------|
| `template.xlsx` | 固定情報（請求者・住所・振込先）入り・数式保持の空テンプレート |
| `fill_expense.py` | JSON の明細を読み込んで完成版 Excel を出力するスクリプト |
| `example.json` | 入力例（2026年2月の実データ相当） |

固定情報は `template.xlsx` に埋め込み済み（倉田速音 / NEWSポストセブン編集部 /
Steenz / 楽天銀行 カノン支店 普通 2117348 / クラタ ハヤト）。
名義や口座が変わったら `template.xlsx` を直接編集すればよい。

## 使い方

```bash
python3 fill_expense.py example.json -o 2026-02_経費.xlsx
```

依存: `openpyxl`（`pip install openpyxl`）。

## 入力フォーマット（JSON）

```json
{
  "請求日": "2026-02-28",

  "経費": [
    {"日付": "2026-02-28", "支払先": "セブンイレブン", "摘要": "お茶", "金額": 1663, "税率": "8%"}
  ],

  "交通費": [
    {"日付": "2026-02-28", "訪問先": "エイトリンクス", "摘要": "取材"}
  ],

  "出社日": ["2026-02-16", "2026-02-18", "2026-02-20"]
}
```

### 交通費はとにかく簡単に

中央林間⇔神保町の出社はほぼ固定（電車・1,180円）なので、**日付を並べるだけ**でよい。

```json
"出社日": ["2026-02-16", "2026-02-18", "2026-02-20", "2026-02-26", "2026-02-27"]
```

これだけで「電車／中央林間⇔神保町／小学館ビル／出社／1,180円／インボイスあり」の
行が日付分まとめて生成される。取材など内容が違う日は `交通費` 配列で個別指定し、
変えたい項目（`訪問先` `摘要` `金額` `手段` `区間from` `区間to`）だけ書けば、
残りは出社の既定値が使われる。

### 税率

- `"10%"`（省略時のデフォルト）→ セルに `0.1`（パーセント書式）
- `"8%"` または `"軽減"` → `軽減8%`
- `"非課税"` → `非/不課税`

1枚の領収書で税率が混在する場合は、税率ごとに行を分けて入力する
（同じ証票番号を共有してよい。例: `example.json` のセブンイレブン2行）。

### インボイス

`"インボイス": true/false`（省略時 true）。適格請求書発行事業者**以外**への
支払い（個人タクシー等）は `false` にする。チェックを外すと消費税控除の集計欄が変わる。

## 制約

- 1シートの明細は最大20行（16〜35行目）。超える場合は分割して複数ファイルにする。
- スクリプトは値を埋めるだけで、合計は Excel／表計算ソフトで開いた時に再計算される。
  openpyxl は数式を計算しないので、出力直後にスクリプトで合計値は読めない（仕様）。
